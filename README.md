## Overview

This repository documents five hands-on cybersecurity mini projects completed as part of my internship training. The projects cover computer networking, packet analysis, network scanning, Python-based packet sniffing, and Linux access control.

## Projects

| Project | Topic | Tools |
|---|---|---|
| [Mini Project 1](Project-1-Network-Simulation/) | Office LAN Network Simulation | Cisco Packet Tracer |
| [Mini Project 2](Project-2-Wireshark/) | Network Traffic Analysis | Wireshark |
| [Mini Project 3](Project-3-Nmap/) | Network and Port Scanning | Nmap, Python |
| [Mini Project 4](Project-4-Packet-Sniffer/) | Python Packet Sniffer | Python, Scapy |
| [Mini Project 5](Project-5-Linux-Permissions/) | Linux Users and File Permissions | Ubuntu, WSL2 |

## Key Learning Outcomes

- Designed and tested a small office LAN with IP addressing and connectivity checks.
- Analyzed DNS, HTTP, and TCP network traffic.
- Practiced authorized localhost port scanning using Nmap.
- Captured and inspected packets using Python and Scapy.
- Configured Linux users, groups, directory ownership, and file permissions.
- Verified successful authorized access and blocked unauthorized access.

## Security and Ethics

All practical activities were performed in controlled, local, or authorized environments for educational purposes. No third-party systems were targeted without permission.
