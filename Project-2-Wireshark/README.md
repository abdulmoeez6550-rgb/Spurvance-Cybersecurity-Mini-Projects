# Mini Project 2 — Wireshark Network Traffic Analysis

## Objective
Capture and analyze network traffic using Wireshark to understand DNS, HTTP, and TCP protocols.

## Tools
- Wireshark
- Windows 11

## Procedure
1. Open Wireshark and select the active network interface.
2. Start capturing network packets.
3. Generate DNS and HTTP traffic.
4. Stop the capture and apply protocol filters.

## Wireshark Display Filters

DNS:
```text
dns
```

HTTP:
```text
http
```

TCP:
```text
tcp
```

## Observations
- DNS traffic demonstrates domain-name resolution.
- HTTP traffic demonstrates unencrypted web requests and responses.
- TCP traffic demonstrates connection-oriented communication.

## Result
Network traffic was captured and analyzed using Wireshark.
